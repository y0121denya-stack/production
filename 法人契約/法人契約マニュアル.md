## 1. 法人契約とは

琴似・西区の会社に**福利厚生**として契約してもらい、社員さんやそのご家族に通ってもらう契約。

- 契約・お支払い：**会社に1つ**（会社名のアカウント）。請求もまとめて1つ
- **法人からの事前の申請がないと利用できない**（社員さんが直接来ても、申請がなければ利用不可）
- 通う方：**お名前（フルネーム）で登録**。社員さんの**ご家族（同居の方のみ）も登録可能**
- 登録した方：個人のお客様と同じく**カウンセリング → カルテ作成**
- 登録した方は全員、**ジム通い放題**＋**パーソナル月2回**
- **初回30分無料サービスはなし**（個人のお客様とはここが違う）

## 2. 料金（税込）

### 2-1. 2027年3月末までのご契約（キャンペーン価格）

**1人 月8,800円・ジム通い放題は実質0円。契約中はずっとこの価格（Aコースと同じ扱い）。**

| 登録人数 | パーソナル回数（月） | 月額 |
|---|---|---|
| 1名 | 2回 | 8,800円 |
| 2名 | 4回 | 17,600円 |
| 3名 | 6回 | 26,400円 |
| 4名 | 8回 | 35,200円 |
| 5名〜 | 人数 × 2回 | 人数 × 8,800円 |

※回数は「1人あたり月2回」で計算。ご家族も1名として数える

### 2-2. 2027年4月以降のご契約

**1人 月9,900円**（回数の考え方は同じ）。
**8,800円になるのは3月末までのご契約だけ。**

### 2-3. 初期費用など（4月以降のご契約も同じ）

| 項目 | 通常 | 法人契約 |
|---|---|---|
| 入会金 | 22,000円 | **0円** |
| 年会費（1法人契約につき） | 11,000円 | **初年度0円**（2年目から11,000円 → 3章） |
| 最低契約期間 | — | **6か月** |
| 違約金 | — | **なし**（ただし6か月分の会費は必ずお支払い → 6章） |

- 年会費は「1人ごと」ではなく「1法人につき」なので、**人数が多い会社ほど1人あたりの負担が小さい**

### 2-4. お得さの伝え方（どちらか一方で伝える）

1. 「Aコース通常12,100円より、**月3,300円お得**です」
2. 「パーソナル月2回の料金で、**ジム通い放題が0円**です」

### 2-5. 営業の締切として使う一言

> 「**2027年3月末までのご契約なら、1人8,800円。契約中はずっとこの価格です。**」

## 3. 請求・お支払い

| 項目 | 内容 |
|---|---|
| 請求のタイミング | **利用月の月末** |
| 月の途中から始めた月・人数を増やした月 | **日割りなし。1か月分を請求** |
| お支払い方法 | **クレジットカード** または **お振込み（請求書を発行）** |
| お振込みの期限 | **翌月の月末まで** |
| 2年目からの年会費（11,000円） | **利用開始月の翌年同月の会費と一緒に請求** |

例）11月分 → 11月30日に請求 → お振込みなら12月31日まで

例）2026年12月に利用開始 → 2027年12月分の会費と一緒に年会費11,000円を請求（2027年12月末）

## 4. 申請と登録

### 4-1. はじめの申請（契約時）

- 法人から、**通う方のお名前（フルネーム）**を事前に知らせていただく
- ご家族を登録する場合は、**どの社員さんのご家族か**も一緒に聞く

### 4-2. 人数を増やすとき

- いつでも可能
- **利用開始希望日に合わせて登録する**ので、**当日からでも利用可能**
- 法人から、増える方のフルネームを事前に知らせていただく
- 増えた方の会費は、**月の途中からでも1か月分**（日割りなし）

### 4-3. 初回来館までのやり取り

- **法人を通しても、社員さんと直接でもOK**（どちらでやり取りするか、申請時に確認する）
- 初回来館時にカウンセリング → カルテ作成

### 4-4. ご家族の登録

- **同居の方のみ**
- **身分証明書の確認はしない**（契約は法人なので、登録した方の行動の責任は法人にある）
- ご家族も社員さんと同じく、**ご自分で2枠〜予約できる**

## 5. 人数の減少・入れ替え・解約

### 5-1. ルール一覧

| 手続き | 申請できる時期 | 反映 | 最初の6か月 |
|---|---|---|---|
| 増やす | いつでも | 利用開始希望日から（当日も可） | **可** |
| 入れ替え（退職・異動など） | **月1回まで無料** | 月の末日までに申請 → **再来月の1日**から | **可** |
| 減らす | 6か月目の1日から | **申請した月の翌月末**まで利用 → その翌日から減る | **不可**（最初に登録した人数のまま） |
| 解約 | 6か月目の1日から | **申請した月の翌月末**で解約 | **不可**（→5-3 早期解約） |

- **どの日に始めても、始めた月を1か月目と数える**（例：11月20日開始でも、11月が1か月目）
- 6か月を過ぎたら、**毎月自動更新**
- **違約金はなし**

### 5-2. 日付の例（11月契約の場合）

- 2026年11月に契約 → 11月・12月・1月・2月・3月・4月が最初の6か月
- **2027年4月1日から**、解約・人数を減らす申請ができる
- 2027年4月に解約を申請 → **2027年5月末で解約**
- 2027年4月に人数を減らす申請 → 5月末まで今の人数 → **6月1日から**減る

### 5-3. 6か月以内にやめたいとき（早期解約）

- **最低契約期間6か月分の会費は、必ずお支払いいただく**
- 例）契約から3か月でやめる → **残り3か月分の会費を全額お支払い**いただいて早期解約
- **倒産などの場合も、お支払いの義務はある**

## 6. 予約アプリ（スコラ）の登録

| 登録 | 数 | 役割 |
|---|---|---|
| 会社の**法人登録** | 1つ | **会費の請求だけ** |
| 社員さん（ご家族）の**個別登録** | 登録人数分 | **パーソナルの予約用**（会費は取らない） |

- 予約は**通う方ご本人が、ご自分の登録から、ご自分のお名前で**入れる
- 会社のご担当者さまがまとめて予約する形ではない
- 登録名の例：法人 `【法人】○○株式会社`／個人 `○○株式会社　山田太郎様`

## 7. 回数のシェア（振り分け）

1人2枠の回数を、社内で「Aさんの枠をBさんへ」と振り分けられる。

### 7-1. ルール

| 項目 | 内容 |
|---|---|
| 申請の締切 | **シェアしたい月の15日まで**（その月の中の予約が対象） |
| 受け取れる枠 | **1人2枠まで** |
| 受け取った人の上限 | **最大4枠**（自分の2枠＋受け取り2枠） |
| 対象 | 同じ法人に登録している方の間（ご家族も含む） |

例）11月15日までに申請 → 11月中の予約でシェアが使える

### 7-2. お店でやる手順

1. 法人（ご担当者さま）から、**15日まで**にシェアの申請をもらう（法人向けメール or 法人対応LINE）
2. 受け取る人が**2枠を超えていないか**確認する（合計4枠まで）
3. スコラの回数を調整する
   - 渡す人：その枠を**潰す**
   - 受け取る人：**チケットを発行**する
4. 記録を残す（誰から誰へ・何枠・どの月）

## 8. お客様へのご案内方針

### 8-1. 伝え方

- 「**社員さんの運動の機会づくりに**」
- 「**福利厚生として**」

### 8-2. こちらからは言わないこと（聞かれたら店長へ）

次の質問は、**こちらから話題にしない**。聞かれたら
**「確認してお返事します」** と答え、内容を店長に投げる。

- 健康経営（健康経営優良法人など）の認定に使えるか
- 税金の扱い（福利厚生費になるか、など）

### 8-3. よくある質問への答え方

| 質問 | 答え方 |
|---|---|
| 使い切れなかった回はどうなる？ | 個人のお客様と同じ扱い |
| 支払い方法は？ | クレジットカード、またはお振込み（請求書を発行・翌月末まで） |
| 請求はいつ？ | 利用月の月末 |
| 月の途中から始めたら？ | 日割りはなく1か月分。始めた月を1か月目と数える |
| 年会費はいつ？ | 初年度0円。2年目からは、利用開始月の翌年同月の会費と一緒に請求 |
| 家族も使える？ | 同居のご家族なら登録可能。ご家族も月2枠予約できる |
| 申請した日から使える？ | 利用開始希望日に合わせて登録するので、当日からでも可能 |
| 初回の無料体験は？ | 法人契約には初回30分無料はない |
| 途中で人数を減らせる？ | 最初の6か月は不可。6か月目から申請でき、申請した月の翌月末まで利用 |
| 退職・異動で人を替えたい | 月1回まで無料で入れ替え可（最初の6か月でも可） |
| 最低何か月？ | 6か月。その後は毎月自動更新 |
| 違約金は？ | なし。ただし最低6か月分の会費はお支払いが必要 |
| 3か月でやめたい | 残り3か月分の会費をお支払いいただければ早期解約できる |
| 枠を他の人に回せる？ | 当月15日までの申請で、1人2枠まで受け取れる（最大4枠） |
